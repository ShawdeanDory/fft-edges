四幅图按课程模板的 A4 通栏版心制作，导出宽度均为 **16 cm**。模板正文为五号（10.5 pt），中文为宋体，英文和数字为 Times New Roman；图内文字为 10 pt，与模板题注样式协调。导出后插入 Word 时保持 16 cm 宽、锁定纵横比。不要把四图再次缩成窄列。

图中只有必要的子图标签、坐标、图例与测量数值，未加入结果解释、优劣判断或自己的分析。以下图注应作为 Word 中的可编辑文字排在图下，而非合成进图片。

## 可直接使用的图注

**图1 RGB通道频谱及中间响应。** 固定示例为 bsds_2018。(a)–(c) 为 R、G、B 通道的对数幅度谱，各通道分别按自身最大值映射灰度，不能根据显示亮度比较通道绝对能量；(d)、(e) 分别为强种子响应和弱连接门控响应，显示范围均为 0–1；(f) 为最终边缘。频谱来自补边图像，响应和边缘已裁回原图尺寸。

**图2 固定示例的六方法边缘检测结果。** 示例为 bsds_3063。(a) 为原始图像，(b) 为人工边界并集，仅用于显示；(c)–(h) 依次为 RGB 主方法、灰度 FFT＋相位、Sobel、Canny、理想高通和高斯高通。各面板显示完整原图范围，保持原生纵横比。P、R 分别表示查准率和查全率；面板下方数值均为该图的官方匹配评分。评分使用每位标注者的原始边界，而非显示并集。示例沿用原稿预先固定的图像，不依据本次美化结果重新选择。

**图3 完整200图的模块配对差值。** 从上至下依次为无相位时加入颜色、有相位时加入颜色、灰度路径加入相位、RGB路径加入相位、增加弱连接门控。(a)–(c) 分别为查准率、查全率与匹配计数汇总 F1 的变化，单位为百分点。圆点表示配对差值点估计，线段表示区间，虚线表示零差值。P/F1 为 99.5% 双侧校正区间，Recall 为 95% 描述区间。区间由 200 张图像进行 20,000 次配对 bootstrap 得到。参数和阈值固定，移除相位会改变响应标度。

**图4 固定10图的高斯噪声实验。** (a) 为六种方法的匹配计数汇总 F1，横轴为名义 RGB 通道高斯噪声标准差；阴影仅表示 RGB 主方法的边际 95% 区间。(b) 为 RGB 主方法相对灰度及 Canny 的 F1 差值，单位为百分点；点表示差值点估计，线段为六项比较采用的 99.1667% 双侧校正区间。非零噪声强度使用三个种子，在图内先平均匹配计数，再以 10 张图像为块进行 bootstrap；干净图每图只有一个输入。独立图像数为 10，种子重复不视为额外独立图像。

## 内容对应与数据来源

- 图1：原稿方法部分，使用既有 bsds_2018 MAT 中的 logSpectra、seedResponse、linkResponse 和 RGB 主方法掩膜。
- 图2：原稿六方法比较部分，使用既有 bsds_3063 图像、全部标注显示并集、六方法掩膜及单图 P/R/F1。
- 图3：原稿模块消融部分，直接读取 ablation_paired_intervals.csv 的 P/R/汇总 F1，共 15 个配对差值。CSV 中另外保留的 5 行 macroF1 不在原图的三个指标范围内，仍完整留在源文件中。
- 图4：原稿噪声部分，完整使用 noise_summary.csv 的 24 行（六方法 × 四档强度），右图沿用原图限定的两个对照及三档非零强度，共 6 项 F1 比较。未从数据中重新计算或替换统计区间。

源文件及原仓库路径对应见 source_data/provenance.json。图像不裁剪、不改亮度或伽马、不膨胀或重算二值边缘；缩小显示时只使用抗锯齿重采样，避免细线因最近邻下采样而断裂。所有原始数组和评分保留。

## 重绘方法

在本目录运行：

```powershell
python -m pip install -r requirements-figures.txt
python plot_paper_figures_cn.py
```

在原仓库也可执行 `python scripts/plot_paper_figures_cn.py`。脚本自动定位本目录 source_data，不依赖旧机器清单中的绝对路径。在其他系统运行时可指定字体文件：

```powershell
python plot_paper_figures_cn.py --chinese-font "宋体字体文件路径" --latin-font "Times字体文件路径"
```

本次只重绘四幅图，Word 论文的图像替换和全篇分页尚未修改。保持原稿的四个图号，整体流程图另见《整体流程图_生图提示词.md》，仅提供提示词，未生成流程图。

## 版式选择说明

按用户要求，课程模板的宋体 / Times New Roman 优先于通用科研图技能的无衬线默认字体。保持固定 16 cm 画布，使用显式边距而非 tight 自动裁切，以保证导出宽度和最终字号稳定。噪声图保留全部六种方法，故采用六色并辅以线型和标记区分；不为减少颜色而删去方法。无需 TIFF 投稿文件，提供 PNG/PDF/SVG 三种格式。
