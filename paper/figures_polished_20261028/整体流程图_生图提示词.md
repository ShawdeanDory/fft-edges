为一篇中文本科课程技术报告绘制一张“基于二维傅里叶变换与相位支持的彩色图像边缘检测”整体算法流程图。图的任务是准确展示处理顺序和两条支路如何汇合，不加入实验结果、优越性结论或解释性长段文字。

**版式与视觉要求**

白色背景，扁平、简洁、适合论文打印的矢量示意图风格。最终插入宽度 16 cm，横向约 16∶10，采用两至三行的分组模块布局。将连续的 FFT、频域导数、逆 FFT 步骤归入“频域梯度”分组，将张量融合、幅值与方向、NMS 归入“梯度融合”分组；不要把每一个操作都铺成同一行的独立大框。相位支路位于主梯度支路下方，连通与输出分组位于右侧或末行。模块边界和箭头清晰，留白均匀、严格对齐，禁止交叉连线和遮挡。主处理支路使用低饱和深蓝 #235789，相位支路使用低饱和青绿 #3F8D8A，灰度辅助模块使用浅灰；文字深灰。不要使用渐变、立体效果、阴影、发光或装饰图标。

全部中文必须为规范简体，字体为宋体 SimSun；英文、数字、数学符号为 Times New Roman 或与正文协调的数学字形。中文标签简短，按最终宽度保证约 10 pt 可读字号。只画图本身，不在图上写“图1”、大标题、图注、来源、水印或制作说明。可用简洁矩形模块和明确箭头，小型输入/输出图像只作为示意，不伪造真实预测或数值。

**需要严格绘制的计算结构**

1. 左侧输入模块：“RGB图像”。分出灰度 Y 与 R、G、B 通道。灰度由原 uint8 RGB 图像先转换再归一化，颜色通道归一化至 0–1。图上简写为“灰度 Y 与 RGB通道”。

2. 主梯度支路按以下顺序连接：

“对称补边” → “二维FFT” → “频域高斯导数” → “逆FFT与裁边” → “灰度 / RGB梯度张量” → “张量融合” → “边缘幅值与方向” → “非极大值抑制与归一化”。

“频域高斯导数”模块内仅放两行简式：

Dx = 2πiu Hσ，Dy = 2πiv Hσ

在“张量融合”模块内放置简式：J = 0.75 JY + 0.25 JRGB。RGB张量为三个颜色通道梯度外积的平均，灰度与颜色梯度均由同一普通二维傅里叶高斯导数流程计算。不要把它画成三个通道的二值边缘并集。

“非极大值抑制与归一化”输出标记为 N。归一化使用原始边缘幅值最大值，不表示三个通道各自产生二值边缘。

3. 从“灰度 Y 与 RGB通道”分出第二条相位支路，与梯度支路并行：

“Log-Gabor频域滤波” → “最大相位一致性矩” → “灰度 / 颜色相位支持” → “融合相位支持 Q”。

RGB颜色相位支持使用各颜色通道梯度能量加权；用一条清晰的细辅助箭头，从主梯度支路的“灰度 / RGB梯度张量”前的梯度输出连接到相位支路的“灰度 / 颜色相位支持”，箭头标签仅写“通道梯度能量”。相位支路输出模块内可写：Q = 0.75 QY + 0.25 QRGB。

相位一致性来自多尺度 Log-Gabor 频域滤波，不能把它画成直接提取原图 FFT 的频谱相角。

4. N 与 Q 汇入“共同相位支持”模块，模块内写：S = N(0.75 + 0.25Q)。

5. 从 S 清楚分出两个并行模块，均连接到最后的连通重建模块：

上方：“强种子”及公式 Sseed = S，阈值 Sseed ≥ 0.32。

下方：“弱连接门控”及公式 Slink = S[1 − 0.125(1 − Q)]，阈值 Slink ≥ 0.096。

把 Q 另接至“弱连接门控”作为门控输入。强种子不施加这一次额外门控，但它此前已经经过共同相位支持；不要画成强种子绕过所有相位处理。

6. 强种子和弱连接图共同输入：“8邻接连通重建” → “细化与边框清零” → “最终二值边缘”。

只保留与强种子连通的弱响应；这是依据已有强种子的连通重建，不是对所有弱响应直接输出。

**准确性限制**

保持上述并行与合流关系，避免为了排版改变算法顺序。只用普通二维 FFT，不出现四元数、深度学习、训练网络、GPU、各向异性高斯核或不存在的模块。不放 Precision、Recall、F1 或任何实验成绩，不写“显著提升”“抗噪更好”“创新点”等分析性结论。图中文字只包含模块名、必要公式、数据流标签及两处阈值。所有中文与公式必须清晰、拼写准确。
