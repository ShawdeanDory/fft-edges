# 纯相位门控：减小Recall损失的固定计划

诊断12图的种子/弱连接损失之后固定6个配置：保留强种子、两档轻种子约束、整体半强度、沿切向相位桥接、灰度/颜色相位取最大保护。无各向异性计算。
只在原12图选择：Precision高于原RGB，Recall损失不超过1个百分点，宏平均F1不低于原RGB；按汇总F1、宏平均F1、Recall、Precision、编号依次择优。无合格候选则停止，不扩网格。
固定高阈值.32、低高比.3、原sigma/相位参数与RGB张量，不追加全局阈值搜索。
冻结一个候选后，与灰度、原RGB、旧纯相位门控在另外88图同批评分。
主目标四项：相对原RGB的Precision、汇总F1、宏平均F1，以及相对旧纯相位门控的Recall；20000次按图配对bootstrap，四个主要差值采用98.75%双侧区间。Recall相对原RGB点估计损失还须<=1个百分点。
不设允许F1下降的正非劣效容忍界值，跨0不称稳定维持；同时报告逐图提高/下降数。
灰度为固定参照，RGB原方法也保留。旧RGB实验包装入口已按用户要求改为纯相位门控，旧包装源码保存在previous_entry/，历史结果不覆盖。
100张val历史上均已观察，本轮仍为探索性补充验证；12图不算确认集。200图test不参与，不根据88图继续选参数。
